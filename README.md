# LUME

Next-gen LED firmware for modern ESP32 boards (S3 / C3) — aiming to be as easy as WLED out of the box, with the motion quality of high-end architectural lighting.

> ⚠️ **Under active reconstruction.**
> This project is mid-cleanup. The docs are intentionally sparse right now: the previous README oversold features that don't fully exist yet (headline AI control, one-click OTA), so it was **removed rather than patched** — a patched README would just launder open bugs into "documented behavior."
>
> A new, honest README lands once the foundation work is done. Until then, the source is the source of truth.
